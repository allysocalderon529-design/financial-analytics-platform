# CLAUDE.md — legal-navigator

Язык: русский. Юридические термины и аббревиатуры не переводить.

## Жёсткие правила

1. **Не выдумывать реквизиты.** Номер, дату, название акта, номер статьи пиши только после того, как
   открыл первоисточник в этой сессии (WebFetch/WebSearch). Не открыл — пиши «Допущение:» и как проверить.
2. **Актуальная редакция.** Для каждого акта в отчёте указывай, на какую дату сверена редакция
   и где (URL). Акт утратил силу или изменён — отметь это явно.
3. **Иерархия.** Федеральный уровень → региональный (субъект) → муниципальный → ведомственные акты
   → судебная практика (позиции ВС РФ, КС РФ). Не смешивай уровни.
4. **Маркеры:** «Проверено:» (открыл источник, есть URL), «Скорее всего:» (вывод из косвенного),
   «Допущение:» (не проверял). Не смешивай уровни в одном предложении.
5. **Не заключение.** Каждый отчёт заканчивается блоком «Риски и непроверенное» и пометкой,
   что документ требует проверки юристом.
6. **Пополнение базы.** Если при разборе нашёл значимый акт, которого нет в `kb/`, добавь его
   в нужный `kb/npa/*.yaml` с `verified: <дата сверки>` и прогони `python3 scripts/validate_kb.py`.

## Команды

```bash
python3 scripts/validate_kb.py
python3 scripts/pick.py projects/<имя>/profile.yaml [--format md]
python3 -m unittest discover -s tests
```
