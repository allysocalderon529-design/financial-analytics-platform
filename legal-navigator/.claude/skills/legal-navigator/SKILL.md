# legal-navigator

Результат — `projects/<slug>/report.md` по `templates/report.md`. Не юридическое заключение.

## 1. Анкета → профиль
- Если `projects/<slug>/profile.yaml` нет — проведи интервью по `intake/questionnaire.md`.
  Спрашивай только то, что меняет подбор: регион, субъект, разбираемый вопрос, флаги.
- Флаги — строго из таблицы анкеты. Нужного флага нет — добавь строку в таблицу и
  используй его в `triggers` новых актов.
- Запиши профиль, покажи пользователю список флагов одной строкой.

## 2. Стартовый подбор
```bash
python3 scripts/pick.py projects/<slug>/profile.yaml
```
Это база, не потолок. Списки ниже пополняют её.

## 3. Углубление под вопрос (обязательно)
Для **разбираемого вопроса** пройди по уровням и найди нормы сверх базы:
1. Федеральный закон/кодекс → конкретные статьи, регулирующие вопрос.
2. Подзаконные: ПП РФ, приказы ведомств (Минстрой, Минприроды, Минцифры, ФНС, РКН и т.д.).
3. Региональный слой: `kb/regions/<код>-*.yaml` → законы субъекта, региональные льготы.
4. Муниципальный: ПЗЗ, генплан (для стройки).
5. Практика: позиции ВС РФ / КС РФ, письма Минфина/ФНС по спорным местам.
6. Изменения: принятые, но не вступившие в силу нормы; законопроекты на regulation.gov.ru / sozd.duma.gov.ru.

Для широкого вопроса с множеством источников — skill `anthropic-skills:deep-research`.

## 4. Сверка (без неё акт в отчёт не идёт как «Проверено»)
Для каждого акта, на который опирается вывод:
- Открой первоисточник (WebFetch/WebSearch): pravo.gov.ru / publication.pravo.gov.ru — официальный текст;
  consultant.ru / garant.ru — актуальная редакция.
- Сверь: номер, дату, название, действует ли, дата последней редакции, номер статьи.
- Запиши в отчёт URL и дату сверки. В `kb/npa/*.yaml` обнови `verified: <сегодня>`;
  исправь реквизиты, если в базе ошибка. Новый значимый акт — добавь записью.
- Не открылось — маркер «Допущение:» и как проверить.

## 5. Отчёт
- Заполни `templates/report.md` → `projects/<slug>/report.md`. Все 5 блоков; пустой блок — «не применимо, потому что…».
- Шаблоны документов: каркасы из `templates/docs/`, подставь реквизиты проекта.
  Нужен Word — skill `anthropic-skills:docx`.
- Маркеры «Проверено: / Скорее всего: / Допущение:» дословно.

## 6. Завершение
```bash
python3 scripts/validate_kb.py -q
python3 -m unittest discover -s tests
```
Коммит: профиль, отчёт, обновления `kb/`.
