# legal-navigator

Подбор правовой части под проект: Claude skill и база знаний.

По анкете проекта собирает:
1. **Сопутствующее законодательство** по разбираемому вопросу (ФЗ, кодексы, подзаконные акты, региональный уровень).
2. **Чек-лист НПА** с конкретными статьями и требованиями.
3. **Риски и разрешения**: лицензии, согласования, экспертизы, сроки, ответственность.
4. **Шаблоны документов**: какие нужны и их структура.
5. **Меры поддержки**: льготы, субсидии, особые режимы (ТОР, СПВ, Арктическая зона, СЗПК, СПИК и т.д.).

Домены: инвест/гос-проекты, стройка/инфраструктура, IT/AI, бизнес/корпоратив.

## Как это работает

```
анкета (intake/questionnaire.md)
  → профиль проекта (projects/<имя>/profile.yaml: домены + флаги + регион)
  → scripts/pick.py: детерминированный подбор актов из kb/ по флагам
  → skill: сверка актуальной редакции в первоисточнике + углубление под конкретный вопрос
  → отчёт по templates/report.md → projects/<имя>/report.md
```

База (`kb/`) — **стартовый набор**, а не исчерпывающий перечень. Skill обязан искать
сверх базы, а найденное значимое — добавлять в `kb/`.

## Быстрый старт

```bash
cd legal-navigator
python3 scripts/validate_kb.py                       # проверка базы
python3 scripts/pick.py projects/_example/profile.yaml   # подбор по профилю
python3 -m unittest discover -s tests                # тесты
```

В Claude Code (из корня этого репо): «разбери правовую часть проекта X» → сработает skill
`legal-navigator` (`.claude/skills/legal-navigator/SKILL.md`).

## Принципы достоверности

- В базе у каждого акта есть поле `verified`: дата последней сверки редакции. `null` означает, что не сверялось.
- В отчёте реквизиты акта (номер, дата, статья) — только из первоисточника, проверенного в этой же сессии.
- Источники: pravo.gov.ru / publication.pravo.gov.ru (официальные), consultant.ru, garant.ru (актуальные редакции).
- Отчёт — аналитическая подготовка, **не** юридическое заключение. Финальная проверка — юрист.

## Структура

| Путь | Что |
|---|---|
| `.claude/skills/legal-navigator/SKILL.md` | workflow для Claude |
| `CLAUDE.md` | правила работы в репо |
| `intake/questionnaire.md` | анкета проекта, словарь флагов |
| `kb/npa/*.yaml` | федеральные акты по доменам |
| `kb/regions/*.yaml` | региональный слой (код субъекта) |
| `templates/report.md` | структура отчёта |
| `templates/docs/` | каркасы документов |
| `scripts/pick.py` | подбор актов по профилю |
| `scripts/validate_kb.py` | валидация базы, поиск устаревших сверок |
| `projects/` | профили и отчёты по проектам |
