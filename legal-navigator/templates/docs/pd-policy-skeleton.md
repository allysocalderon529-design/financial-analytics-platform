# Политика оператора в отношении обработки персональных данных

**Оператор:** {{наименование, ОГРН, ИНН, адрес}}

1. Общие положения — правовые основания (152-ФЗ, иные акты), сфера действия.
2. Цели обработки — для каждой цели: категории ПДн, категории субъектов, способы, сроки, порядок уничтожения.
3. Правовые основания обработки по каждой цели (согласие, договор, закон).
4. Условия обработки — локализация баз данных в РФ, поручение обработки третьим лицам.
5. Трансграничная передача — страны, основание, уведомление РКН (если применимо; сверить актуальный порядок).
6. Права субъектов ПДн и порядок их реализации.
7. Меры по обеспечению безопасности ПДн.
8. Ответственный за организацию обработки, контакты.
9. Заключительные положения — порядок публикации и актуализации.

Политика должна быть опубликована (для онлайн-сбора ПДн — на сайте). Сверить актуальную редакцию 152-ФЗ и требования РКН.
