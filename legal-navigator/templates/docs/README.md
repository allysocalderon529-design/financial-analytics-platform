# Каркасы документов

Каркасы задают **структуру**, а не готовый текст. Содержание пункта и ссылки на нормы
skill подставляет после сверки редакции. Перед использованием — проверка юристом.

| Файл | Когда нужен |
|---|---|
| `contract-skeleton.md` | любой гражданско-правовой договор проекта |
| `application-skeleton.md` | заявление / заявка в орган власти или оператору меры поддержки |
| `pd-policy-skeleton.md` | политика обработки ПДн (флаг `personal-data`) |

Нужен новый каркас — добавь файл и строку в эту таблицу.
